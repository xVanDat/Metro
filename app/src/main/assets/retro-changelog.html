v26.09.26

Library and storage

  • Fixed folder blacklisting on Android 13 and 14 with the system folder picker.
  • Added blacklist support for removable SD cards.
  • Added per-song hiding with a screen for restoring hidden tracks.
  • Added M3U, M3U8, PLS, XSPF, WPL and ASX playlist-file import.
  • Added full library rescanning and accent-insensitive search.
  • Extended backups to include blacklist, history, play counts and the current queue, and fixed a crash while creating backups.

Playback

  • Added resume positions for long tracks, playback bookmarks and safe ReplayGain normalization.
  • Improved synchronized lyrics and fixed delayed lyrics in the custom player themes.
  • Added album-art colors to the full lyrics screen.
  • Replaced the narrow player overflow popup with a full-screen options menu.

Appearance and usability

  • Added Animated Gradient, YouTube Music and Spotify-inspired offline player themes.
  • Added custom TTF/OTF font selection through Android Files.
  • Simplified the player-theme selector and reorganized Settings.
  • Renamed For You to Home and added time-aware greetings.
  • Limited the interface to complete English and Vietnamese resources and fixed language switching on Android 14.
